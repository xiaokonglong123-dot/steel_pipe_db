## 页面与能力

| 路由 | 能力 |
| --- | --- |
| `/login` | 登录（先领 CSRF）、失败提示；锁定/限流提示沿用后端文案 |
| `/tubes` | 状态/库位/质量/钢级筛选、分页、勾选批量出库、跳详情 |
| `/tubes/:id` | 全字段 + 类型扩展 + 流转历史；出库/调拨/质量标注/找回/软删（按角色） |
| `/stock-in` | 入库表单（无缝/筛管分流），下拉库位带 `used_count/capacity` |
| `/import` | 文件或粘贴 CSV，展示逐行失败原因 |
| `/locations` | 列表 + 新建 + 停用/启用（admin 可写） |
| `/standards` | 列表 + 新增 + 删除（admin 可写） |
| `/checks`、`/checks/:id` | 开单、逐根核对（一致/盘亏/移库）、盘盈登记、确认（admin）、取消 |
| `/users` | 新建、启停、吊销会话、重置口令（admin） |
| `/audit` | 最近 200 条 + action 过滤 + 一键校验哈希链（admin） |

## 工程要点

1. **类型来源单一**：所有 DTO 从 `openapi.json` 生成的 `schema.d.ts` 取，页面不手写接口结构；CI 有漂移检查。
2. **CSRF 与刷新**：`api/client.ts` 统一从 `csrf_token` cookie 取 token 塞 `X-CSRF-Token`；`401` 先用 refresh cookie 静默刷新一次再重放（A13），并发刷新合并成一次请求。
3. **权限前置**：`SessionProvider` 暴露 `isAdmin/canWrite`，导航项与路由守卫同时判断；后端仍是最终裁决。
4. **设计 token 复用**：旧 `app.css` 的配色/密度/圆角变量原样移植，Bootstrap 覆盖层不再需要。
5. **单二进制**：`rust-embed` 内嵌 `web/dist`；改动前端后必须重新 `cargo build` 才会生效（README 已注明）。
