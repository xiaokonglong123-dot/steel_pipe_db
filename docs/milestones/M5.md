steelpipe reconcile                     → used_count 无漂移
steelpipe audit verify                  → 审计链校验通过：0 条 / 0 批 / tip=2e3874e8…

steelpipe seed-standards --path std.csv → 新增 2 条 / 跳过 0 条

## 本轮新增

| 位置 | 内容 |
| --- | --- |
| `service/import.rs` | CSV 流式导入：必填列校验、行数上限 10 000、BOM 容错、可选列、筛管参数、逐行事务 |
| `service/ops.rs` | `verify_chain`（分批 + tip 比对）、`reconcile`（漂移修复 + 审计）、`seed_standards`（幂等种子） |
| `api/routes/tubes.rs` | `POST /api/tubes/import`（`text/csv`），返回 `{total, inserted, failed[]}` |
| `server/cli_ops.rs` | 三个 CLI 子命令，操作者取第一个启用 admin（无则 `cli` 身份） |
| `cli.rs` | 全局 `--database`（默认读 env / `sqlite://data/steelpipe.db`）、`seed-standards --path` |

## 关键语义

1. **行级部分成功**：每行独立 `Uow`，失败行不阻塞后续行，也不留半成品（管子/扩展表/单据/审计同事务）。
2. **超限整体拒绝**：先读入内存计数再写，10 001 行时 0 行入库。
3. **链校验的 tail 一致性**：除逐条哈希外，最后再与 `audit_chain_tip.last_hash` 比对，能抓到"链本身自洽但链尾表被改"的情况。
4. **对账写审计**：修复 `used_count` 也是业务写入，记 `reconcile_used_count` 行，可追溯。
