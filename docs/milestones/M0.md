## 结构

```text
Cargo.toml                    workspace（members = crates/*，exclude = rust-core）
rust-toolchain.toml           stable + rustfmt/clippy
crates/api/                   HTTP 层：routes / error(RFC 9457) / OpenAPI；不依赖 sqlx
crates/infra/                 持久层：DbPool(SqlitePool)、PRAGMA、sqlx::migrate!、WRITE_TXN_BEGIN；不依赖 axum
  migrations/0001_init.sql    audit_chain_tip 单行表（CHECK id=1）+ 创世 hash
crates/server/                单二进制：serve / openapi / audit verify / reconcile
  build.rs                    web/dist 缺失时放占位，保证 cargo build 不依赖前端顺序
web/                          Vite 8 + React 19 + TS strict（M0 只有状态页）
scripts/ci/layering.sh        分层断言（api ⊁ sqlx/infra，infra ⊁ axum/api）
.github/workflows/ci.yml      rust 作业 + contract 作业（构建 → 生成 → 漂移检查）
```

## 关键约束已被钉住

1. **fail-fast 保留**：`STEELPIPE_JWT_SECRET` 为空或 < 32 字节 → `serve` 直接拒绝启动（设计 §9.4）。`Config` 的 `Debug` 手写实现，密钥只打印字节数。
2. **创世哈希固定**：`sha256("AYANAMI_REI_GENESIS") = 2e3874e8…cd40`，SQL 迁移与 `steelpipe_infra::AUDIT_GENESIS_HASH` 双处一致，并有单测比对。旧链迁移时不会断在第一条。
3. **审计链尾单行**：`audit_chain_tip` 用 `CHECK (id = 1)` 保证唯一；写入协议收敛为 `infra::WRITE_TXN_BEGIN = "BEGIN IMMEDIATE"` 单一常量，M3 只在这一个入口上写业务 + 审计。
4. **PRAGMA 逐连接生效**：`journal_mode=WAL`、`synchronous=NORMAL`、`foreign_keys=ON`、`busy_timeout=5000`，由 `SqliteConnectOptions` 施加，测试断言而非口头约定。
5. **分层由 CI 断言**：`api` 认不出数据库驱动（探活走 `DbProbe` trait），`infra` 认不出 HTTP。
6. **错误体统一**：`ApiError` → RFC 9457，M1 起只追加变体，不改调用方。

## 复查命令

```bash
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
bash scripts/ci/layering.sh
cargo build --workspace --bins
(cd web && npm run build)

# 冒烟（不配库也能跑）
export STEELPIPE_JWT_SECRET=$(openssl rand -base64 48)
export STEELPIPE_BIND=127.0.0.1:18080
./target/debug/steelpipe serve &
curl -s localhost:18080/api/health
curl -s -o /dev/null -w '%{http_code}\n' localhost:18080/          # 200
curl -s -o /dev/null -w '%{http_code}\n' localhost:18080/api/nope  # 404
kill %1

# 冒烟（接入 SQLite，含迁移）
export STEELPIPE_DATABASE_URL="sqlite://data/steelpipe.db"
./target/debug/steelpipe serve &
curl -s localhost:18080/api/health/db                              # 200 {"status":"ok",...}
sqlite3 data/steelpipe.db "select id,last_seq,last_hash from audit_chain_tip"
kill %1

# 契约管道
./target/debug/steelpipe openapi > openapi.json
(cd web && npm run gen:api)
```
