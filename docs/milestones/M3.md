## 本轮新增

| 位置 | 内容 |
| --- | --- |
| `crates/service/src/inventory.rs` | 入库（合规门禁 + 强制入库审计）、单根出库、批量原子出库、调拨、质量标注、软删、列表/详情/历史读侧 |

| `crates/api/src/error.rs` | RFC 9457 补 `422 unprocessable` / `409 state-conflict`；`ApiReject` 装箱避免 `result_large_err` |
| `crates/infra/src/repo/` | `tubes`（条件 UPDATE、软删、历史、扩展表）、`locations`（原子 used_count + drift/refresh）、`transactions`、`standards` |

## 关键语义

1. **入库单一事务**：管子 + 类型扩展 + 入库单据 + 明细 + `used_count` + 审计在同一条 `BEGIN IMMEDIATE` 里。
2. **批量出库原子**：先全量做守卫再写；任一失败整体回滚，`transactions` 也不新增（测试断言 3 → 3）。
3. **调拨双侧计数**：源 `-1`、目标 `+1`，跨事务失败会一起回滚。
4. **态冲突返回 409**：`InventoryError::Conflict` / `Domain(TubeError)` 都映射到 `state-conflict`，与旧实现 `ConflictError` 语义对齐。
5. **软删释放计数**：软删在库管子时 `used_count -1`（旧实现残留，属缺陷）。
