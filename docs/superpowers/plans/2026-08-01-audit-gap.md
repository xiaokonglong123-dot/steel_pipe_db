# 审计缺口修复实施计划（用户管理 + 标准管理写操作审计）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用户管理 4 操作与 standards 3 写操作写入审计哈希链（同一 `BEGIN IMMEDIATE` 事务），操作者记录到 `audit_logs.user_id`，失败路径零审计残留。

**Architecture:** 复用现有 `audit_service._write_audit`（纯 Rust 哈希 + 链尖读 DB）。user_service 4 函数加必填 `*, actor_id: int` 并在既有 `begin_immediate` 事务内补 `_write_audit` 调用；新建 `standards_service.py`（raw conn + begin_immediate + _write_audit，与 user_service 同模式），standards 路由瘦身为薄壳。`delete_standard` 硬删前将被删行值快照进审计 detail（数据保全）。

**Tech Stack:** Python 3.11 / FastAPI / SQLAlchemy 2.x async / SQLite (WAL) / rust_core (PyO3, `anyio.to_thread` 调 `_write_audit` 已内建)

## Global Constraints

- 项目**不是 git 仓库**：本计划所有任务**不含 git commit 步骤**；每个任务以「全量回归测试通过」收尾。
- 所有状态变更操作 **MUST** 使用 `begin_immediate`（`src/modules/warehouse/services/audit_service.py`），审计行 MUST 与业务操作同事务写入。
- `AuditLog.user_id` = 操作者（actor），与管操作现有语义一致。
- **绝不**在 audit detail 中记录密码/哈希（`$argon2` 不得出现）。
- `actor_id` 为必填 keyword-only 参数（`*, actor_id: int`），不允许默认值（杜绝"可跳过审计"路径）。
- 测试 MUST 沿用现有文件模式：独立 DB（`data/test_*.db`）、env 预置先于 app import、`sys.path.insert`、`_stub_user`/`_allow_csrf`/`client`/`fx` fixture（参照 `tests/test_audit_route.py`）。
- 运行测试用 `.venv/bin/python -m pytest`，工作目录为项目根。全量回归：`.venv/bin/python -m pytest -m "not slow" -q`（基线 96 passed；本计划完成后应变为 109 passed + 3 deselected）。
- 表单 POST 一律带 `csrf_token` 字段（值为任意串，如 `"test-csrf"`），因 handler 的 `csrf_token: str = Form(...)` 是必填参数（`require_csrf` 依赖覆写只豁免校验，不豁免字段）。
- 原始 async conn 上 `select(ORM 实体)` 只返回主键而非实体（项目已知坑，memory #103）——需要行值时用**显式列 select + `fetchone()`**。

```python
"""API 5CT standard spec service — create, update, delete with audit.

All operations use ``raw conn + begin_immediate`` and write the audit
entry inside the same transaction (project convention #13). The deleted
row's values are snapshotted into the audit detail before the hard delete
so the audit chain remains the only record of removed reference data.
"""

from __future__ import annotations

from sqlalchemy import select
from sqlalchemy.exc import IntegrityError

from src import database as db
from src.models import StandardSpec
from src.modules.warehouse.services.audit_service import (
    _write_audit,
    begin_immediate,
)


class StandardConflictError(Exception):
    """A StandardSpec with the same grade already exists."""


def _detail(grade: str, od: float, min_wt: float, max_wt: float) -> str:
    return (
        f"grade={grade} od={od} min_wt={min_wt} max_wt={max_wt}"
    )


async def create_standard(
    steel_grade: str,
    outer_diameter_mm: float,
    min_wall_thickness_mm: float,
    max_wall_thickness_mm: float,
    engine: object = None,
    *,
    actor_id: int,
) -> None:
    eng = engine or db.engine
    async with eng.connect() as conn:
        await begin_immediate(conn)
        grade = steel_grade.strip()
        try:
            await conn.execute(
                StandardSpec.__table__.insert().values(
                    grade=grade,
                    outer_diameter_mm=outer_diameter_mm,
                    min_wall_thickness_mm=min_wall_thickness_mm,
                    max_wall_thickness_mm=max_wall_thickness_mm,
                )
            )
        except IntegrityError:
            await conn.rollback()
            raise StandardConflictError(
                f"grade '{grade}' already exists"
            ) from None
        await _write_audit(
            conn, "create_standard",
            _detail(grade, outer_diameter_mm, min_wall_thickness_mm,
                    max_wall_thickness_mm),
            user_id=actor_id,
        )
        await conn.commit()


async def update_standard(
    spec_id: int,
    steel_grade: str,
    outer_diameter_mm: float,
    min_wall_thickness_mm: float,
    max_wall_thickness_mm: float,
    engine: object = None,
    *,
    actor_id: int,
) -> None:
    eng = engine or db.engine
    async with eng.connect() as conn:
        await begin_immediate(conn)
        row = (
            await conn.execute(
                select(StandardSpec.id).where(StandardSpec.id == spec_id)
            )
        ).fetchone()
        if row is None:
            await conn.rollback()
            raise ValueError(f"standard spec {spec_id} not found")
        grade = steel_grade.strip()
        try:
            await conn.execute(
                StandardSpec.__table__.update()
                .where(StandardSpec.id == spec_id)
                .values(
                    grade=grade,
                    outer_diameter_mm=outer_diameter_mm,
                    min_wall_thickness_mm=min_wall_thickness_mm,
                    max_wall_thickness_mm=max_wall_thickness_mm,
                )
            )
        except IntegrityError:
            await conn.rollback()
            raise StandardConflictError(
                f"grade '{grade}' already exists"
            ) from None
        await _write_audit(
            conn, "update_standard",
            _detail(grade, outer_diameter_mm, min_wall_thickness_mm,
                    max_wall_thickness_mm),
            user_id=actor_id,
        )
        await conn.commit()


async def delete_standard(
    spec_id: int,
    engine: object = None,
    *,
    actor_id: int,
) -> None:
    eng = engine or db.engine
    async with eng.connect() as conn:
        await begin_immediate(conn)
        row = (
            await conn.execute(
                select(
                    StandardSpec.grade,
                    StandardSpec.outer_diameter_mm,
                    StandardSpec.min_wall_thickness_mm,
                    StandardSpec.max_wall_thickness_mm,
                ).where(StandardSpec.id == spec_id)
            )
        ).fetchone()
        if row is None:
            await conn.rollback()
            raise ValueError(f"standard spec {spec_id} not found")
        await conn.execute(
            StandardSpec.__table__.delete().where(StandardSpec.id == spec_id)
        )
        await _write_audit(
            conn, "delete_standard",
            _detail(row.grade, row.outer_diameter_mm,
                    row.min_wall_thickness_mm, row.max_wall_thickness_mm),
            user_id=actor_id,
        )
        await conn.commit()
```

> 注意：原始 async conn 上 `select(StandardSpec)` 只返回主键（项目已知坑），故存在性检查用 `select(StandardSpec.id)`、删除快照用**显式列 select + `fetchone()`**（`row.grade` 等为 Row 具名访问，可靠）。
