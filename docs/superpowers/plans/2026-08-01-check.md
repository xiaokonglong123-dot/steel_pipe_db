## Goal

实现库存盘点 `/tubes/check`：选择库位 → 逐根核对（ok/missing/moved/surplus）→ 报告 → **管理员原子确认**（单 BEGIN IMMEDIATE 应用全部差异 + transaction(type=check) + 审计）→ 找回恢复。设计文档 §17 缺口「盘点」关闭。

## Architecture

- **check_sessions / check_items** 两新表（迁移 4，纯新表 + 1 索引）
- **check_service.py** 新服务：raw conn + begin_immediate（同 user_service 风格），全部函数返回 dict
- **stock_in 核心提取**：`_insert_tube_with_compliance(conn, ...)` 接收已打开连接（调用方持事务）；`stock_in` 变薄壳——现有 14 项入库测试守护
- **确认原子性**：confirm_check 单事务内逐项应用；任一项失败 → 整体回滚、session 保持 open、零审计零部分应用
- 盘亏 → 新状态 `missing`；找回 → `recover`；盘盈走 compliance 门
- 审计：仅 confirm（action=check，detail 含差异计数）与 recover（action=recover）；创建/标记/取消不审计（盘点单表留痕）

## Tech Stack

Python 3.11+ / FastAPI async / SQLAlchemy 2.x async / SQLite WAL / Jinja2 SSR（Bootstrap 5.3.3 CDN + design tokens）/ Alembic

## Global Constraints

1. 所有状态变更必须 `begin_immediate`（`src/modules/warehouse/services/audit_service.py`），审计写入与业务同事务
2. TOCTOU 守卫：`WHERE ... AND status='in_stock' AND deleted_at IS NULL AND quality_mark != 'scrapped'` + `rowcount == 1` 断言
3. `locations.used_count` 增减必须与业务操作同事务（`AND used_count>0` 防下溢）
4. 所有 POST 路由 `Depends(require_csrf)` + 表单 `csrf_token` 隐藏字段；错误重渲染用 `csrf_token_for(request)` + `set_csrf_cookie(返回的 Response)`
5. 错误映射：`CheckConflictError` → 409 重渲染；`ValueError`（表单字段缺失）→ 422 重渲染；`ComplianceError` → 422 重渲染（同 do_stock_in 先例）
6. 路由权限：核对/标记/盘盈/删除/取消/报告 → `require_operator`；确认 → `require_admin`
7. 迁移：新表用 `op.create_table`（非 ALTER，无需 batch_alter_table）；revision id 与文件名一致；`down_revision="8ce24f163996"`；验证用临时 DB（`DATABASE_URL=sqlite+aiosqlite:///data/test_migration_check.db alembic upgrade head`，之后删除临时文件）
8. **项目不是 git 仓库**：所有任务不含 commit 步骤；测试运行即验收

**Step 1 — check_service.py**（全文，注意与上面接口完全一致）：

```python
"""Inventory check (盘点) service — D11.

All functions use raw conn + ``begin_immediate`` (same pattern as
user_service). Check sessions are DB-persisted; ``confirm_check`` applies
all differences atomically in ONE ``BEGIN IMMEDIATE`` transaction
(spec §4.3) — any failure rolls the whole txn back and keeps the session
``open`` (zero partial application, zero audit on failure).
"""

from __future__ import annotations

import json
from datetime import datetime, timezone
from typing import Any

from sqlalchemy import text

from src import database as db
from src.models import CheckItem, CheckSession
from src.modules.warehouse.services.audit_service import (
    ConflictError,
    begin_immediate,
)
from src.modules.warehouse.services.tube_service import _generate_pipe_id


class CheckConflictError(ConflictError):
    """409 for check-flow state conflicts (non-open session, bad marks)."""


CHECK_STATUSES = ("open", "confirmed", "cancelled")
CHECK_RESULTS = ("ok", "missing", "moved", "surplus")


def _now() -> datetime:
    return datetime.now(timezone.utc)


async def _load_session(conn, check_id: int) -> dict:
    row = (
        await conn.execute(
            text("SELECT * FROM check_sessions WHERE id=:i"), {"i": check_id}
        )
    ).fetchone()
    if row is None:
        raise CheckConflictError(f"check session {check_id} not found")
    return dict(row._mapping)


async def _require_open(conn, check_id: int) -> dict:
    sess = await _load_session(conn, check_id)
    if sess["status"] != "open":
        raise CheckConflictError(
            f"check session {check_id} is {sess['status']} (not open)"
        )
    return sess


async def create_check(
    location: str,
    operator_id: int,
    remark: str | None = None,
    engine: object = None,
) -> dict:
    eng = engine or db.engine
    async with eng.connect() as conn:
        await begin_immediate(conn)
        loc = (
            await conn.execute(
                text("SELECT 1 FROM locations WHERE code=:c AND is_active=1"),
                {"c": location},
            )
        ).fetchone()
        if loc is None:
            await conn.rollback()
            raise CheckConflictError(f"location '{location}' not found or inactive")
        res = await conn.execute(
            CheckSession.__table__.insert().values(
                location=location,
                status="open",
                created_by=operator_id,
                remark=remark,
                created_at=_now(),
            )
        )
        check_id = res.inserted_primary_key[0]
        await conn.commit()
        return {"id": check_id, "location": location}


async def get_check(check_id: int, engine: object = None) -> dict:
    eng = engine or db.engine
    async with eng.connect() as conn:
        return await _load_session(conn, check_id)


async def list_checks(engine: object = None) -> list[dict]:
    eng = engine or db.engine
    async with eng.connect() as conn:
        rows = (
            await conn.execute(
                text("SELECT * FROM check_sessions ORDER BY id DESC")
            )
        ).all()
        return [dict(r._mapping) for r in rows]


async def get_check_detail(check_id: int, engine: object = None) -> dict:
    eng = engine or db.engine
    async with eng.connect() as conn:
        sess = await _load_session(conn, check_id)
        items = (
            await conn.execute(
                text(
                    "SELECT * FROM check_items WHERE check_id=:c ORDER BY id"
                ),
                {"c": check_id},
            )
        ).all()
        tubes = (
            await conn.execute(
                text(
                    "SELECT pipe_id, steel_grade, outer_diameter_mm, "
                    "wall_thickness_mm, length_m, quality_mark, location "
                    "FROM tubes WHERE location=:l AND status='in_stock' "
                    "AND deleted_at IS NULL ORDER BY pipe_id"
                ),
                {"l": sess["location"]},
            )
        ).all()
        locations = (
            await conn.execute(
                text(
                    "SELECT code FROM locations WHERE is_active=1 ORDER BY code"
                )
            )
        ).all()
        return {
            "session": sess,
            "items": [dict(r._mapping) for r in items],
            "tubes": [dict(r._mapping) for r in tubes],
            "locations": [r._mapping["code"] for r in locations],
        }


async def mark_item(
    check_id: int,
    pipe_id: str,
    result: str,
    actual_location: str | None = None,
    actor_id: int = 0,
    engine: object = None,
) -> dict:
    if result not in CHECK_RESULTS:
        raise CheckConflictError(f"invalid result '{result}'")
    eng = engine or db.engine
    async with eng.connect() as conn:
        await begin_immediate(conn)
        sess = await _require_open(conn, check_id)
        tube = (
            await conn.execute(
                text("SELECT * FROM tubes WHERE pipe_id=:p AND deleted_at IS NULL"),
                {"p": pipe_id},
            )
        ).fetchone()
        if tube is None:
            await conn.rollback()
            raise CheckConflictError(f"pipe '{pipe_id}' not found")
        tm = dict(tube._mapping)
        if tm["location"] != sess["location"] or tm["status"] != "in_stock":
            await conn.rollback()
            raise CheckConflictError(
                f"pipe '{pipe_id}' not in_stock at '{sess['location']}'"
            )
        act_loc = actual_location.strip() if actual_location else None
        if result == "moved":
            if not act_loc:
                raise ValueError("actual_location required for moved")
            if act_loc == sess["location"]:
                await conn.rollback()
                raise CheckConflictError(
                    "actual_location must differ from session location"
                )
            loc = (
                await conn.execute(
                    text("SELECT 1 FROM locations WHERE code=:c AND is_active=1"),
                    {"c": act_loc},
                )
            ).fetchone()
            if loc is None:
                await conn.rollback()
                raise CheckConflictError(
                    f"location '{act_loc}' not found or inactive"
                )
        existing = (
            await conn.execute(
                text(
                    "SELECT id FROM check_items "
                    "WHERE check_id=:c AND pipe_id=:p"
                ),
                {"c": check_id, "p": pipe_id},
            )
        ).fetchone()
        if existing is not None:
            await conn.execute(
                CheckItem.__table__.update()
                .where(CheckItem.__table__.c.id == existing[0])
                .values(
                    result=result,
                    actual_location=act_loc,
                    surplus_data=None,
                )
            )
        else:
            await conn.execute(
                CheckItem.__table__.insert().values(
                    check_id=check_id,
                    pipe_id=pipe_id,
                    result=result,
                    actual_location=act_loc,
                    created_at=_now(),
                )
            )
        await conn.commit()
        return {"pipe_id": pipe_id, "result": result}


async def add_surplus(
    check_id: int,
    surplus_data: dict,
    actor_id: int = 0,
    engine: object = None,
) -> dict:
    eng = engine or db.engine
    async with eng.connect() as conn:
        await begin_immediate(conn)
        await _require_open(conn, check_id)
        pipe_type = surplus_data["type"]
        pipe_id = _generate_pipe_id(
            pipe_type,
            surplus_data["steel_grade"],
            surplus_data["outer_diameter_mm"],
            surplus_data["wall_thickness_mm"],
        )
        existing = (
            await conn.execute(
                text(
                    "SELECT 1 FROM tubes "
                    "WHERE pipe_id=:p AND deleted_at IS NULL"
                ),
                {"p": pipe_id},
            )
        ).fetchone()
        if existing is not None:
            await conn.rollback()
            raise CheckConflictError(f"pipe_id '{pipe_id}' already exists")
        res = await conn.execute(
            CheckItem.__table__.insert().values(
                check_id=check_id,
                pipe_id=pipe_id,
                result="surplus",
                surplus_data=json.dumps(surplus_data, ensure_ascii=False),
                created_at=_now(),
            )
        )
        await conn.commit()
        return {"pipe_id": pipe_id, "item_id": res.inserted_primary_key[0]}


async def delete_surplus_item(
    check_id: int,
    item_id: int,
    actor_id: int = 0,
    engine: object = None,
) -> None:
    eng = engine or db.engine
    async with eng.connect() as conn:
        await begin_immediate(conn)
        await _require_open(conn, check_id)
        item = (
            await conn.execute(
                text(
                    "SELECT * FROM check_items WHERE id=:i AND check_id=:c"
                ),
                {"i": item_id, "c": check_id},
            )
        ).fetchone()
        if item is None:
            await conn.rollback()
            raise CheckConflictError(f"check item {item_id} not found")
        if dict(item._mapping)["result"] != "surplus":
            await conn.rollback()
            raise CheckConflictError("only surplus items can be deleted")
        await conn.execute(
            text("DELETE FROM check_items WHERE id=:i"), {"i": item_id}
        )
        await conn.commit()

    engine: object = None,

    eng = engine or db.engine
    async with eng.connect() as conn:
        await begin_immediate(conn)
        res = await conn.execute(
            text(
                "UPDATE check_sessions SET status='cancelled' "

        )
        if res.rowcount != 1:
            await conn.rollback()
            raise CheckConflictError(
                f"check session {check_id} cannot be cancelled (not open)"
            )
        await conn.commit()
```

```python
async def confirm_check(
    check_id: int,
    actor_id: int,
    engine: object = None,
) -> dict:
    """Atomically apply all differences of an open check session.

    ONE ``BEGIN IMMEDIATE`` transaction: every item is applied (missing →
    status='missing' + used_count-1; moved → location=actual + used_count
    migration; surplus → stock-in via the compliance core). Any failure
    raises → the whole txn rolls back, the session stays ``open`` and no
    audit row is written (zero partial application, spec §4.3).
    """
    eng = engine or db.engine
    async with eng.connect() as conn:
        await begin_immediate(conn)
        sess = await _require_open(conn, check_id)
        location = sess["location"]
        rows = (
            await conn.execute(
                text("SELECT * FROM check_items WHERE check_id=:c ORDER BY id"),
                {"c": check_id},
            )
        ).all()
        items = [dict(r._mapping) for r in rows]
        missing_n = surplus_n = moved_n = 0
        now = _now()

        for it in items:
            if it["result"] == "ok":
                continue
            if it["result"] == "missing":
                missing_n += 1
                r = await conn.execute(
                    text(
                        "UPDATE tubes SET status='missing', updated_at=:n "
                        "WHERE pipe_id=:p AND location=:l AND status='in_stock' "
                        "AND deleted_at IS NULL AND quality_mark != 'scrapped'"
                    ),
                    {"p": it["pipe_id"], "l": location, "n": now},
                )
                if r.rowcount != 1:
                    await conn.rollback()
                    raise CheckConflictError(
                        f"pipe '{it['pipe_id']}' not in_stock at '{location}' — re-check"
                    )
                await conn.execute(
                    text(
                        "UPDATE locations SET used_count=used_count-1 "
                        "WHERE code=:l AND used_count>0"
                    ),
                    {"l": location},
                )
            elif it["result"] == "moved":
                moved_n += 1
                target = it["actual_location"]
                loc = (
                    await conn.execute(
                        text(
                            "SELECT 1 FROM locations "
                            "WHERE code=:c AND is_active=1"
                        ),
                        {"c": target},
                    )
                ).fetchone()
                if loc is None:
                    await conn.rollback()
                    raise CheckConflictError(
                        f"location '{target}' not found or inactive"
                    )
                r = await conn.execute(
                    text(
                        "UPDATE tubes SET location=:t, updated_at=:n "
                        "WHERE pipe_id=:p AND location=:l AND status='in_stock' "
                        "AND deleted_at IS NULL AND quality_mark != 'scrapped'"
                    ),
                    {"p": it["pipe_id"], "l": location, "t": target, "n": now},
                )
                if r.rowcount != 1:
                    await conn.rollback()
                    raise CheckConflictError(
                        f"pipe '{it['pipe_id']}' not in_stock at '{location}' — re-check"
                    )
                await conn.execute(
                    text(
                        "UPDATE locations SET used_count=used_count-1 "
                        "WHERE code=:l AND used_count>0"
                    ),
                    {"l": location},
                )
                await conn.execute(
                    text(
                        "UPDATE locations SET used_count=used_count+1 "
                        "WHERE code=:t"
                    ),
                    {"t": target},
                )
            elif it["result"] == "surplus":
                surplus_n += 1
                data = json.loads(it["surplus_data"])
                await _insert_tube_with_compliance(
                    conn,
                    type_=data["type"],
                    outer_diameter_mm=data["outer_diameter_mm"],
                    wall_thickness_mm=data["wall_thickness_mm"],
                    length_m=data["length_m"],
                    steel_grade=data["steel_grade"],
                    location=location,
                    operator_id=actor_id,
                    manufacturer=data["manufacturer"],
                    pipe_id=it["pipe_id"],
                    thread_type=data.get("thread_type"),
                    api_5ct_cert=data.get("api_5ct_cert"),
                    batch_no=data.get("batch_no"),
                    heat_no=data.get("heat_no"),
                    heat_treat_method=data.get("heat_treat_method"),
                    quality_mark=data.get("quality_mark", "normal"),
                    quality_note=data.get("quality_note"),
                    seamless_specs=data.get("seamless_specs"),
                    screen_specs=data.get("screen_specs"),
                    compliance_pass=None,  # 盘盈走合规（spec §4.3）
                )

        txn_res = await conn.execute(
            Transaction.__table__.insert().values(
                type="check",
                operator_id=actor_id,
                remark=f"check {check_id}",
                created_at=now,
            )
        )
        txn_id = txn_res.inserted_primary_key[0]
        for it in items:
            if it["result"] == "ok":
                continue
            src = location if it["result"] in ("missing", "moved") else None
            tgt = (
                it["actual_location"]
                if it["result"] == "moved"
                else (location if it["result"] == "surplus" else None)
            )
            await conn.execute(
                TransactionItem.__table__.insert().values(
                    transaction_id=txn_id,
                    pipe_id=it["pipe_id"],
                    source_location=src,
                    target_location=tgt,
                )
            )

        await _write_audit(
            conn,
            "check",
            f"check_id={check_id} location={location} "
            f"missing={missing_n} surplus={surplus_n} moved={moved_n}",
            actor_id,
        )

        await conn.execute(
            text(
                "UPDATE check_sessions SET status='confirmed', "
                "confirmed_by=:a, confirmed_at=:t WHERE id=:i"
            ),
            {"a": actor_id, "t": now, "i": check_id},
        )
        await conn.commit()
        return {
            "check_id": check_id,
            "missing": missing_n,
            "surplus": surplus_n,
            "moved": moved_n,
        }


async def recover_missing(
    pipe_id: str,
    actor_id: int,
    engine: object = None,
) -> dict:
    """Restore a missing (盘亏) tube back to in_stock."""
    eng = engine or db.engine
    async with eng.connect() as conn:
        await begin_immediate(conn)
        tube = (
            await conn.execute(
                text("SELECT * FROM tubes WHERE pipe_id=:p AND deleted_at IS NULL"),
                {"p": pipe_id},
            )
        ).fetchone()
        if tube is None:
            await conn.rollback()
            raise CheckConflictError(f"pipe '{pipe_id}' not found")
        tm = dict(tube._mapping)
        if tm["status"] != "missing":
            await conn.rollback()
            raise CheckConflictError(
                f"pipe '{pipe_id}' is not missing (status={tm['status']})"
            )
        r = await conn.execute(
            text(
                "UPDATE tubes SET status='in_stock', updated_at=:n "
                "WHERE pipe_id=:p AND status='missing' AND deleted_at IS NULL"
            ),
            {"p": pipe_id, "n": _now()},
        )
        if r.rowcount != 1:
            await conn.rollback()
            raise CheckConflictError(f"pipe '{pipe_id}' recovery failed")
        loc = tm["location"]
        await conn.execute(
            text(
                "UPDATE locations SET used_count=used_count+1 WHERE code=:l"
            ),
            {"l": loc},
        )
        txn_res = await conn.execute(
            Transaction.__table__.insert().values(
                type="check",
                operator_id=actor_id,
                remark="recover",
                created_at=_now(),
            )
        )
        txn_id = txn_res.inserted_primary_key[0]
        await conn.execute(
            TransactionItem.__table__.insert().values(
                transaction_id=txn_id,
                pipe_id=pipe_id,
                source_location=loc,
                target_location=None,
            )
        )
        await _write_audit(
            conn, "recover", f"pipe_id={pipe_id} location={loc}", actor_id
        )
        await conn.commit()
        return {"pipe_id": pipe_id, "location": loc}
```
