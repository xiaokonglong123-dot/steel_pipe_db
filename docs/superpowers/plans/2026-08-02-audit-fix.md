**Goal:** Fix 7 known defects, rewrite 37 migrations to SQLite syntax (drop legacy industry-specific tables, add items), optionally containerize with Docker Compose, and establish CI pipeline.

**Architecture:** 3 parallel workstreams: (A) code defects fixed in Rust handlers/services, (B) frontend routing fixes + DataIO module creation, (C) migration rewrite from PG-style to SQLite3 with schema changes. Workstreams A & B complete before C.

**Tech Stack:** Rust (Axum 0.8, SQLx 0.8 sqlite), TypeScript 5 (React 19, TanStack Query), SQLite3 (sqlite://data/erp.db?mode=rwc), Docker

## Global Constraints

- Must follow existing codebase patterns: handler/service/repo layers for backend; features/{module}/api,hooks,pages,types.ts,queryKeys.ts for frontend
- No `as any` or `@ts-ignore` in TypeScript
- All DB operations: soft-delete via `deleted_at` column (no hard DELETE)
- Errors use numeric error codes (domain-prefixed, 5-digit)
- Status checks: `cargo check` + `cargo clippy -- -D warnings` at end of each Rust task
- Frontend: `npx tsc --noEmit` + `npm run build` after each frontend task
- Database: SQLite3 only (sqlx sqlite feature); no external DB dependencies

pub async fn approve_inbound(
    pool: &SqlitePool,
    id: i64,
    reason: Option<&str>,
    user_id: i64,
) -> Result<InboundRecord, AppError> {
    let r = InboundRecordRepo::find_by_id(pool, id).await?
        .ok_or(AppError::NotFound("Inbound record not found".into()))?;
    if r.status != "pending" { return Err(AppError::StatusConflict("Only pending records".into())); }
    let updated = InboundRecordRepo::approve(pool, id).await?;
    OperationLogRepo::create(pool, CreateOperationLog {
        user_name: Some(user_id),
        action: "approve_inbound".to_string(),
        entity_type: "inbound".to_string(),
        entity_id: Some(id),
        details: reason.map(|r| format!("Approval reason: {}", r)),
        ip_address: None,
    }).await?;
    Ok(updated)
}
```

- [ ] **Step 4: Modify handlers to pass reason**

pub async fn approve_inbound_handler(

import apiClient from '@/api/client';
export const dataIoApi = {
  importData: (entityType: string, file: File) => {
    const formData = new FormData(); formData.append('file', file);
    return apiClient.postFormData(`/data-io/import/${entityType}`, formData);
  },
  exportData: (entityType: string, params?: Record<string, string>) =>
    apiClient.getBlob(`/data-io/export/${entityType}`, params),
  downloadTemplate: (entityType: string) =>
    apiClient.getBlob(`/data-io/templates/${entityType}`),
  listOperationLogs: (params: { page?: number; page_size?: number }) =>

};

// frontend/src/features/data-io/hooks/useDataIo.ts
import { useQuery, useMutation, useQueryClient } from '@tanstack/react-query';
import { dataIoApi } from '../api/dataIoApi';
export const dataIOQueryKeys = {
  operationLogs: (params?: any) => ['data-io-operation-logs', params] as const,
};

export function useOperationLogs(params?: { page?: number; page_size?: number }) {
  return useQuery({
    queryKey: dataIOQueryKeys.operationLogs(params),
    queryFn: () => dataIoApi.listOperationLogs(params),
  });
}
export function useImportData(entityType: string) {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: (file: File) => dataIoApi.importData(entityType, file),
    onSuccess: () => qc.invalidateQueries({ queryKey: dataIOQueryKeys.operationLogs({}) }),
  });
}
```
