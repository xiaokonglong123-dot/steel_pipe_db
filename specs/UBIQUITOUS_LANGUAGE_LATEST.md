# Ubiquitous Language — ERP 通用术语表

> 来源：steel-pipe-db → ERP 重构对话（2026）。本表为本仓库的**规范术语**，文档、代码、命名必须使用「术语」列词汇，禁止使用「Aliases to avoid」列中的词。
> 历史沿革：本系统由 API 5CT 钢管行业系统重构而来，旧术语一律废弃。

## 商品与库存 (Products & Inventory)

| Term | Definition | Aliases to avoid |
| ---- | ---------- | ---------------- |
| **商品 (Item)** | 可交易的基本业务对象，全系统唯一实体 | 管材、产品、物料、货品 |
| **SKU** | 商品的唯一业务编码，由系统或人工分配 | 管号 (pipe number) |
| **规格 (Spec)** | 商品的描述性属性（可选），不再承载行业强制字段 | 钢级、API 5CT 等级 |
| **库存 (Inventory)** | 商品在库位上的存量记录 | 存货、现货 |
| **仓库 (Warehouse)** | 库存的顶级物理/逻辑容器 | 库区 |
| **库位 (Location)** | 仓库内的具体存放位置，库存归属的最小单位 | 货架号 |
| **入库 (Inbound)** | 商品进入库存的业务动作 | 收货（仅限采购语境） |
| **出库 (Outbound)** | 商品离开库存的业务动作 | 发货（仅限销售语境） |
| **库存预留 (Reservation)** | 为订单预先锁定可用库存（ATP） | 占用、预占 |
| **盘点 (Count Session)** | 周期性核对账面与实物库存的过程 | 盘点单、盘点会话 |

## Relationships

- **商品** 是 **SKU** 描述的对象；每个 **SKU** 唯一标识一个 **商品**
- **库存** 归属于 **库位**；**库位** 归属于 **仓库**
- **采购订单** 从 **供应商** 采购 **商品**；**采购收货** 增加 **库存**
- **销售订单** 向 **客户** 销售 **商品**；**发货** 减少 **库存**
- **库存预留** 绑定到 **销售订单**（或工单），占用可用库存
- **采购订单** / **销售订单** 均可在 **审批流实例** 中流转；**审批任务** 属于一个 **审批流实例**
- **发票**、**付款**、**日记账** 关联到 **采购订单** / **销售订单**
- **工单** 按 **BOM** 消耗 **商品**；**质检** 与 **不合格品单** 关联 **工单**
- **员工** 属于 **部门**；**用户** 分配 **角色**；**角色** 授予 **权限**
- **门户账户** 关联一个 **客户** 或 **供应商**
- **固定资产** 按 **折旧** 规则分摊，经 **资产处置** 退出

## Example dialogue

> **Dev:** "采购模块的 Quote 和销售模块的 Quote 都叫报价，表结构怎么区分？"
> **Domain expert:** "术语上必须带前缀：**采购报价** 来自供应商，**销售报价** 发给客户。表名和路由也分开，杜绝歧义。"
> **Dev:** "旧的 pipes 表里有一堆管材专属字段，还要保留吗？"
> **Domain expert:** "不保留。统一收敛为 **商品** + **SKU** + 可选的 **规格**，行业字段全部删除。"
> **Dev:** "质量证书模块删掉后，制造里的质检用什么词？"
> **Domain expert:** "用 **质检 (Inspection)**，它是工单的质量检验记录，和钢管时代的证书是两回事。"
> **Dev:** "Portal 账户和客户是什么关系？"
> **Domain expert:** "**客户** 是业务实体，**门户账户** 是客户在门户里的登录身份，一个客户可有多个门户账户。"

## Flagged ambiguities

- **「订单」**：曾指采购订单与销售订单两种单据——必须带前缀（采购/销售）使用
- **「报价」**：采购（供应商报价）与销售（客户报价）两个方向——必须带前缀
- **「合同」**：销售合同、采购合同、劳动合同是三种不同实体——必须带前缀
- **「收货」vs「入库」**：收货是采购确认动作，入库是库存动作；两者常同时发生但不是同一概念
- **「发货」vs「出库」**：同理，发货是销售确认动作，出库是库存动作
- **「库存」**：通用库存与 ATP 预留是不同概念，预留是库存的分配视图
- **「报表」vs「BI」**：报表是明细清单，BI 是聚合分析——模块边界不同
- **「资产」**：单独出现时禁止使用（固定资产 vs 门户资产），一律用「固定资产」
